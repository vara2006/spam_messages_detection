# Spam Detection using Deep Learning and NLP

## Project Overview
This project classifies SMS messages as Spam or Ham using Deep Learning and NLP techniques.

## Features
- Text preprocessing
- Tokenization
- Deep Learning model
- Spam prediction
- Accuracy and loss visualization

## Technologies Used
- Python
- TensorFlow
- Keras
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Model Accuracy
Achieved 98% accuracy on test dataset.

## Output
- Confusion Matrix
- Classification Report
- Accuracy Graph
- Loss Graph

## Dataset
SMS Spam Collection Dataset

## How to Run
pip install -r requirements.txt
python spam_detection.py
